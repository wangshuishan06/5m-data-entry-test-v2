**(c)** Explain the difference between a **terminal (emulator)** and a **shell**, and give one example of each.

**Answer:**
```
A terminal (emulator) is the graphical application that handles user input and renders text on screen, 
while a shell is the command-line interpreter running inside it that actually reads, interprets, and executes those commands.
Terminal example: macOS Terminal (Terminal.app)
Shell example: zsh (or bash)
```
